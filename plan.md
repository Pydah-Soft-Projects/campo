# Project: Campo – Premium Institutional Management Platform Website

## 1. Project Overview

We have developed **Campo**, an integrated institutional management platform that brings all our college and campus management applications together into one connected ecosystem.

We have already implemented the integration of our different applications under the Campo platform. Now, we want to build a premium, modern, visually impressive website that introduces Campo, communicates its value, showcases its capabilities, and encourages educational institutions to get in touch with us.

### Technology Stack
- React + Vite
- Tailwind CSS
- JavaScript (prefer JavaScript over TypeScript)
- Framer Motion for animations
- Lucide React for icons
- React Router if multiple pages are required

First, inspect the existing project structure and dependencies. Reuse the existing setup wherever possible. Do not unnecessarily replace or restructure working configurations.

---

## 2. Brand Identity & Design Direction

I have attached the official Campo logo. Use this logo as the primary reference for the entire website's visual identity.

### Brand Colours

Extract and consistently use colours inspired by the logo.

Suggested palette:

- Primary Navy: `#071C46`
- Deep Navy: `#061638`
- Secondary Navy: `#0B2452`
- Primary Teal: `#00C5B5`
- Secondary Teal: `#00AFA5`
- White: `#FFFFFF`
- Light Background: `#F7F9FC`
- Text Primary: `#14213D`
- Text Secondary: `#64748B`

The website should maintain a premium combination of navy blue, teal, white, and subtle neutral backgrounds.

### Important Design Requirements

- The website must feel like a premium international SaaS product.
- Avoid generic template-style landing pages.
- Avoid excessive gradients, unnecessary colourful elements, and random decorative shapes.
- Use whitespace intelligently.
- Maintain consistent spacing, typography, border radiuses, and component styling.
- Use subtle shadows and glass effects only where appropriate.
- Make the overall design elegant, clean, professional, and visually engaging.
- Do not use emojis anywhere on the website.
- Use professional icons and custom visual elements instead.

---

## 3. Typography

Use premium, modern fonts.

Recommended combination:
- Headings: Plus Jakarta Sans or Sora.
- Body: Inter or DM Sans.

Typography should have:
- Strong visual hierarchy.
- Large, bold hero headings.
- Comfortable paragraph readability.
- Proper letter spacing.
- Consistent heading sizes across sections.

Use responsive typography with Tailwind breakpoints or fluid CSS sizing.

## 4. Website Structure

Build a complete, polished landing website with the following sections.

### Section 1: Navigation Bar

Create a premium navigation bar.

Requirements:
- Campo logo on the left.
- Navigation links in the middle/right.
- Links: Home, Platform, Solutions, Features, About Us, Contact.
- A prominent "Request a Demo" button.
- Sticky navigation when scrolling.
- Transparent or subtle styling at the top, transitioning into a solid/light background when scrolling.
- Smooth scrolling to corresponding sections.
- Responsive mobile navigation with an elegant animated menu.

The navigation should be minimal and professional.

### Section 2: Hero Section

This is the most important section.

Create an impressive first impression immediately when visitors open the website.

Main headline inspiration:

"One Institution. One Connected Ecosystem."

Alternative supporting message:

"Everything your institution needs. Connected, intelligent, and working together."

Explain that Campo brings institutional operations, academics, administration, finance, and campus services together through one integrated platform.

Include:
- A strong headline.
- A concise supporting paragraph.
- Primary CTA: "Request a Demo".
- Secondary CTA: "Explore the Platform".
- A visually impressive product showcase.

For the visual showcase, create a premium dashboard-inspired composition showing interconnected institutional applications, analytics, notifications, and information flowing across the platform.

Do not use random stock photos as the main hero visual.

The hero should communicate that Campo is more than a collection of disconnected applications. It is one connected institutional ecosystem.

Add subtle animated elements representing connectivity, data flow, and intelligent operations.

### Section 3: The Problem – Disconnected Systems

Introduce the problems faced by modern educational institutions.

Examples:
- Multiple disconnected applications.
- Scattered institutional information.
- Repetitive administrative processes.
- Delayed decision-making.
- Limited visibility across departments.
- Difficulty coordinating campus operations.

Use a visually engaging layout rather than a plain list of text.

Communicate the idea:

"Managing an institution shouldn't mean managing multiple disconnected systems."

### Section 4: Introducing Campo

Present Campo as the unified solution.

Suggested heading:

"Meet Campo. The Connected Intelligence Behind Your Institution."

Explain how Campo connects different institutional functions into one coordinated ecosystem.

Highlight:
- Centralized institutional operations.
- Connected applications.
- Unified access.
- Permission-based information access.
- Real-time visibility.
- Intelligent notifications and insights.

Use an elegant central ecosystem diagram or an interactive application connection visualization.

Make this section visually distinctive.

### Section 5: Applications & Solutions

Showcase the different applications available within the Campo ecosystem.

Create individual cards or an interactive grid for:

1. Admissions CRM – Manage enquiries, leads, admissions, and the student admission journey.
2. Student Data Management – Centralize student profiles, records, and institutional information.
3. Academic Management – Manage academic operations, schedules, and institutional workflows.
4. Learning Management – Support faculty and student learning activities.
5. Fee Management – Manage fee collection, transactions, concessions, and financial tracking.
6. Examination Management – Organize examination-related processes and academic assessments.
7. HRMS – Manage employee records, attendance, leave, and HR operations.
8. Transport Management – Coordinate routes, vehicles, transport operations, and tracking.
9. Hostel Management – Manage hostel operations, residents, and related activities.
10. Stationery Management – Manage institutional stationery inventory and distribution.
11. Staff Recruitment System – Streamline staff recruitment and hiring workflows.
12. SAMS – Manage campus labour and workforce operations.

Each application card should contain:
- Professional icon.
- Application name.
- Short description.
- Subtle hover animation.
- Consistent visual styling.

Do not make these cards look like ordinary generic dashboard cards.

Use interactive hover effects and visually connect them to the Campo ecosystem.

### Section 6: Intelligent Institutional Operations

Campo is not just about connecting applications. It also helps institutions understand and act on their information.

Create a dedicated section highlighting its AI capabilities.

Suggested heading:

"From Institutional Data to Intelligent Decisions."

Explain these capabilities:

- Ask questions and receive answers using existing institutional information.
- Context-aware notifications.
- Intelligent insights across different applications.
- Better visibility into institutional operations.
- Permission-based information access.
- Support for faster and more informed decisions.

Important distinction:

The implemented AI capability currently answers questions using existing institutional data, respecting the permissions and access scope of individual users.

Present other AI capabilities as configurable or future possibilities where appropriate. Do not falsely claim that every proposed AI feature is already implemented.

Use a premium visual showing an AI assistant interacting with connected institutional data.

### Section 7: How Campo Works

Explain the platform through a simple three-step visual journey:

1. Connect – Bring different institutional applications into one ecosystem.
2. Understand – Access connected information and gain visibility across departments.
3. Act – Make informed decisions and manage institutional operations more effectively.

Use animated illustrations, connected nodes, or a horizontal process timeline.

### Section 8: Why Campo?

Create a premium differentiation section.

Highlight:

- One connected institutional ecosystem.
- Centralized visibility.
- Integrated institutional workflows.
- Role-based access and information security.
- Scalable institutional management.
- Intelligent data-driven operations.
- Reduced fragmentation across departments.

Suggested headline:

"More Than Software. A Better Way to Run Your Institution."

Keep this section concise and visually strong.

### Section 9: Call to Action

Create an impressive CTA section before the footer.

Suggested heading:

"Your Institution Deserves a More Connected Future."

Supporting text:

"Discover how Campo can simplify operations, connect departments, and bring your entire institution into one intelligent ecosystem."

Include:
- Request a Demo button.
- Contact Us button.

Use the brand's navy and teal colours.

## 7. Animation & Interaction Requirements

Animations are an important part of this project.

Use Framer Motion wherever it adds value.

Implement:

1. Smooth scrolling between sections.
2. Subtle fade-in and upward reveal animations.
3. Staggered animations for application cards.
4. Elegant hero entrance animations.
5. Subtle floating elements in the hero visual.
6. Interactive hover effects.
7. Smooth button transitions.
8. Animated counters where meaningful.
9. Scroll-triggered section animations.
10. Subtle transitions between navigation states.
11. Animated ecosystem connections.
12. Mobile menu transitions.

### Scrolling Experience

The website should feel exceptionally smooth while scrolling.

Use:
- CSS scroll-behavior.
- Scroll-triggered animations.
- Proper section spacing.
- Smooth transitions.
- Lightweight effects.

Avoid excessive parallax or animations that make the website slow.

Respect `prefers-reduced-motion` for accessibility.

- Mobile-first implementation.
- No horizontal overflow.
- Responsive typography.
- Properly stacked layouts.
- Mobile-friendly navigation.
- Touch-friendly buttons.

The final website should look like a professionally designed enterprise SaaS platform website.

- Give every section its own visual identity while maintaining consistent branding.
- Prioritize clean layouts, strong typography, thoughtful spacing, and premium interactions.
